## Main Project

### 隊列メーカー

ステージ・パレードの隊列表を作成、共有、PDF書き出しできるWebアプリです。

- React / TypeScript / Vite
- Supabase を使ったクラウド保存・共同作業
- Vercel でのWeb公開
- iPad / PC の操作性を意識したUI
- ステージモード、パレードモード、道具割当、PDF書き出しに対応

[アプリを開く](https://tairetsu-maker.vercel.app/)
